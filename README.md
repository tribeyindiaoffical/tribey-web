# Tribey — Minimal Next.js scaffold

This repo is a starter scaffold for Tribey: a minimal, clean Next.js + TypeScript + Tailwind project for sports booking, runs, treks, and rooms.

Getting started

1. Install dependencies

```bash
npm install
```

2. Run development server

```bash
npm run dev
```

Project layout

- `app/` — Next.js app router pages
- `components/` — small React components
- `styles/` — global CSS (Tailwind)
- `data/mockEvents.json` — sample mock data
